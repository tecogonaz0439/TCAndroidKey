## 2. 本アプリの内容と位置付け

本アプリは、Android 端末を FIDO2 (CTAP 2.0) セキュリティキーとして動作させ、**FIDO / FIDO2 (WebAuthn) を使用する Web アプリケーションの登録・認証を試験するためのテスト用ツール**です。

**本アプリは、YubiKey などの物理セキュリティキーの代替として使用することを想定していません。** 本アプリを、日常の認証手段、本番サービスの多要素認証、アカウントの回復手段として使用しないでください。

本アプリは FIDO Alliance の認定 (FIDO Certified) を受けていません。また、FIDO Alliance、Yubico、Google、その他の第三者が提供、承認、後援、保証するアプリではありません。FIDO、FIDO2、WebAuthn、YubiKey、Android その他の名称は、各権利者の商標または登録商標です。

## 3. 利用の条件

利用者は、次の条件を守って本アプリを利用するものとします。

- 本アプリを登録するのは、**試験用のアカウントおよび試験環境に限ってください。** 本番サービスや重要なアカウントには登録しないでください。
- 試験の対象とする Web アプリケーション (RP) は、利用者自身が管理するもの、または管理者から試験の許可を得たものに限ってください。
- 本アプリを使用する端末には画面ロック (PIN、パターン、パスワード) を設定し、本アプリの鍵が使用できる状態の端末を第三者に渡さないでください。
- 試験が終わった鍵は、本アプリの「クレデンシャル」画面で削除し、試験対象の Web アプリケーション側の登録も削除してください。

## 4. 鍵とデータの取扱い

### 4.1 鍵

本アプリは、登録ごとに秘密鍵を Android Keystore (StrongBox または TEE) の中で生成します。秘密鍵は端末の外へ取り出せず、本アプリから書き出すこともできません。

秘密鍵は Android のバックアップおよび端末移行の対象外です。本アプリのアンインストール、アプリデータの消去、端末の初期化、画面ロックの無効化等により、**鍵は失われ、復旧できません。** 鍵の喪失により試験用アカウントにログインできなくなった場合、その回復は試験対象の Web アプリケーション側の手段によるものとします。

### 4.2 端末内のデータ

本アプリは、次のデータを端末内のアプリ専用領域に保存します。

| データ | 内容 | 保存方法 |
|---|---|---|
| クレデンシャルのメタデータ | RP ID・RP 名、ユーザー ID・ユーザー名・表示名、公開鍵、作成日時・最終使用日時、署名カウンタ | Android Keystore の鍵で暗号化して保存 |
| 設定 | テーマ、受付時間、ワンタイム等の設定 | アプリ専用領域 |
| イベントログ | 登録・認証の結果、RP ID、ユーザー名等 | メモリ内のみ (アプリの終了で消去) |

これらのデータは Android のバックアップおよび端末移行の対象外です。イベントログの一部 (コマンド名と結果のみ。RP ID・ユーザー名は含みません) は、開発時の確認のため Android のシステムログ (logcat) にも出力されます。

保存したデータは、本アプリの「クレデンシャル」画面の削除機能、Android のアプリ情報画面からのストレージの消去、または本アプリのアンインストールで削除できます。

### 4.3 送信しない情報

本アプリはインターネットへの通信を行いません (インターネット接続の権限を持ちません)。氏名、メールアドレス等の登録を求めず、位置情報、端末識別子、広告 ID を取得しません。広告、利用状況の分析、クラッシュ報告の SDK も使用しません。

本アプリが端末外へ送るのは、利用者が操作して NFC または Bluetooth で接続したクライアント (PC、ブラウザ、他の Android 端末等) に対する FIDO2 の応答 (公開鍵、署名、credential ID、ユーザー ID、ユーザー名等) のみです。クライアントおよび Web アプリケーションがこれらの情報をどう扱うかは、それぞれの提供者の規約、ポリシーに従います。

## 5. 権限

本アプリは、次の Android の権限を使用します。

| 権限 | 目的 |
|---|---|
| NFC | NFC のカードエミュレーションでセキュリティキーとして動作するため |
| 生体認証の使用 (USE_BIOMETRIC) | 登録・認証の前の本人確認、削除・設定変更の本人確認のため |
| 付近のデバイス (BLUETOOTH_CONNECT / BLUETOOTH_ADVERTISE) | Bluetooth HID のセキュリティキーとして動作するため (実験的機能。設定で有効にした場合のみ) |
