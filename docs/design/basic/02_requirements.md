# BD-02 要件定義

| 項目 | 内容 |
|---|---|
| 文書番号 | TCAK-BD-02 |
| 版数 | 1.0 |
| 作成日 | 2026-11-02 |
| 関連文書 | BD-01 システム概要、DD-10 テスト仕様 |

状態欄: **済** = 実装済み、**実験** = 実装済みだが動作保証外、**否** = 技術的理由により非対応。

## 1. 前提条件 (PRE)

| ID | 内容 |
|---|---|
| PRE-01 | FIDO / FIDO2 を使用した Web アプリケーションのテスト用として利用する |
| PRE-02 | YubiKey などの物理セキュリティキーの代替としては使用しない (本番アカウントに登録しない) |
| PRE-03 | FIDO 認定を受けた認証器ではない。AAGUID は MDS 未登録 |
| PRE-04 | 鍵のバックアップ・復旧手段はなく、鍵の喪失を許容する |
| PRE-05 | 利用者は開発者・テスト担当者 |

## 2. 機能要件 (FR)

| ID | 要件 | 状態 | 設計 |
|---|---|---|---|
| FR-01 | NFC 接続で FIDO2 認証器 (CTAP 2.0 over NFC) として動作する。主ターゲットとする | 済 | BD-04, DD-02 |
| FR-02 | Bluetooth 接続で FIDO2 認証器として動作する (技術的に可能な範囲) | 実験 | BD-04, DD-03 |
| FR-03 | USB 接続で FIDO2 認証器として動作する (技術的に可能な範囲) | 否 | BD-04 §4 |
| FR-04 | クレデンシャルを登録する (authenticatorMakeCredential、ES256、discoverable / non-discoverable) | 済 | DD-01 §3 |
| FR-05 | 認証する (authenticatorGetAssertion / GetNextAssertion) | 済 | DD-01 §4, §5 |
| FR-06 | 認証器情報を返す (authenticatorGetInfo) | 済 | DD-01 §2 |
| FR-07 | 登録済みクレデンシャルを一覧表示する (RP、ユーザー、作成・最終使用日時、署名回数、種別、保管レベル) | 済 | DD-08 §3 |
| FR-08 | クレデンシャルを個別に削除する | 済 | DD-07 §5 |
| FR-09 | 全クレデンシャルを削除する | 済 | DD-07 §5 |
| FR-10 | クライアント (OS) からの authenticatorReset で全削除する。設定で許可した場合のみ | 済 | DD-01 §6 |
| FR-11 | 認証の前に本人確認 (指紋等) を必須とする | 済 | BD-05 §4 |
| FR-12 | 本人確認後、設定した時間 (15〜300 秒) のみ認証を受け付ける | 済 | DD-05 §2 |
| FR-13 | 1 回の本人確認で受け付ける登録/認証を 1 回に限定できる (既定 ON) | 済 | DD-05 §2 |
| FR-14 | 本アプリが起動して画面に表示されている間のみ認証を受け付ける | 済 | DD-05 §2 |
| FR-15 | 本人確認前にリーダーを検出したら本人確認ダイアログを表示する (設定で無効化可) | 済 | DD-02 §5 |
| FR-16 | アテステーション形式を選択できる (`none` / `packed` 自己アテステーション) | 済 | DD-01 §3.4 |
| FR-17 | 認証器の動作をイベントログとして表示する | 済 | DD-09 §3 |
| FR-18 | 設定画面で各種動作を変更できる (テーマ、受付時間、ワンタイム、生体認証のみ、StrongBox 優先 等) | 済 | DD-06 §4 |

## 3. 非機能要件 (NFR)

| ID | 区分 | 要件 | 状態 |
|---|---|---|---|
| NFR-01 | 動作環境 | Android 15 (API 35) 以上で動作する | 済 (minSdk 35) |
| NFR-02 | 技術スタック | Kotlin 2、Jetpack Compose (Material 3) を使用する | 済 (Kotlin 2.4、Compose BOM 2026.08) |
| NFR-03 | 依存性 | Google Play 開発者サービスを使用しない (GMS 非搭載端末で動作する) | 済 |
| NFR-04 | 鍵保管 | 秘密鍵を OS 標準キーストア (TEE / StrongBox) に格納する | 済 |
| NFR-05 | 性能 | NFC の 1 APDU の応答を、リーダーのタイムアウト内 (目安 1 秒以内) に返す | 済 (実機計測は試験で確認) |
| NFR-06 | 互換性 | Windows 11 / macOS 27 (+ RC-S300/P)、Android 15+ をクライアントとして試験する | 試験で確認 |
| NFR-07 | 多言語 | 日本語・英語 | 済 |
| NFR-08 | UI | TCSameuraDamMonitor-android の UI をベースとし、部品を可能な限り再利用する | 済 |
| NFR-09 | 画面サイズ | スマートフォン〜タブレット・PC 幅 (840dp 以上は常設サイドバー) に対応する | 済 |
| NFR-10 | 開発環境 | クラウドで APK を作成でき、ローカル (macOS + Android Studio) でもビルドできる | 済 |
| NFR-11 | 保守性 | プロトコル処理を Android 非依存モジュールに分離し、単体テストで検証できる | 済 (fido-core) |
| NFR-12 | 業務端末 | 業務用端末 (GMS 非搭載・MDM 管理下) へ APK で導入できる | 済 |

## 4. セキュリティ要件 (SEC)

テスト用ツール (PRE-01) であっても、鍵が不用意に使われない・持ち出されないことを要件とする。

| ID | 要件 | 状態 |
|---|---|---|
| SEC-01 | 秘密鍵を端末外へ取り出せない (Keystore 内で生成・非エクスポート) | 済 |
| SEC-02 | 鍵の使用は本人確認から一定時間内に限る (アプリ側の受付管理 + Keystore 側の認証有効期間) | 済 |
| SEC-03 | 端末ロック中は鍵を使用できない | 済 |
| SEC-04 | アプリが前面に表示されていない間は認証を受け付けない | 済 |
| SEC-05 | クレデンシャル情報 (メタデータ) を暗号化して保存する | 済 |
| SEC-06 | 鍵・メタデータ・設定をバックアップ・端末移行の対象外とする | 済 |
| SEC-07 | 画面のスクリーンショット・画面共有を禁止する | 済 |
| SEC-08 | イベントログを永続化しない | 済 |
| SEC-09 | 削除操作、および保護を弱める設定変更 (ワンタイム OFF、生体認証のみ OFF、リセット許可 ON) には本人確認を要する | 済 |
| SEC-10 | 外部入力 (CTAP/APDU/HID) を検証し、不正な入力で異常終了しない | 済 |
