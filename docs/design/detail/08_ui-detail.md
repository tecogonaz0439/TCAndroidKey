## 2. SC-01 セキュリティキー

### 2.1 受付状態カード

| 状態 | アイコン | タイトル | 補足 | ボタン |
|---|---|---|---|---|
| 画面ロック未設定 | 鍵 | 本人確認が必要です | 画面ロックの設定が必要な旨 | [画面ロックを設定] → セキュリティ設定 |
| 待機 (IDLE) | 鍵 | 本人確認が必要です | 「認証の前に指紋 (または画面ロック) で本人確認してください…」 | [本人確認して開始] (指紋アイコン、全幅) |
| 受付中 | 解錠 (カード背景はプライマリコンテナ色) | 認証できます | 残り N 秒、プログレスバー、「本端末の背面を NFC リーダーにかざしてください」(ワンタイム時は 1 回で終了する旨) | [停止] |

- 最終使用がある場合「最終使用: 日時 (RP ID)」を表示。
- 残り秒数は 250 ms 毎に更新、切り上げ表示。live region (読み上げ) はタイトル (「認証できます / 本人確認が必要です」) のみとし、
  毎秒変わる残り秒数は含めない (TalkBack の反復読み上げを避ける)。

### 2.2 接続方式

| 行 | 状態表示 | 操作 |
|---|---|---|
| NFC | 利用可能 (カードエミュレーション) / NFC がオフです / 非対応 | NFC オフ時 [オンにする] → NFC 設定 |
| Bluetooth HID (実験的) | 設定で無効 / 権限の許可が必要 / Bluetooth がオフ / 停止中 / 開始しています / PC からの接続待ち / 接続中: ホスト名 / エラー / 利用できません | [設定] (無効時) / [開始] / [停止]。接続待ち時は [この端末を検出可能にする] |
| USB | 非対応 (理由) | なし |

### 2.3 鍵の保管

「Android キーストア (StrongBox 利用可)」または「(TEE)」、「N 件のクレデンシャル」、[管理] → SC-02。

### 2.4 最近のイベント

最新 5 件 (ログ行形式は §4)。なしの場合「イベントはありません」。[すべて表示] → SC-03。

## 3. SC-02 クレデンシャル

| 要素 | 内容 |
|---|---|
| 説明 | 鍵は端末外へ出ないこと、削除は取り消せないこと |
| [すべて削除] | エラー色のアウトラインボタン。1 件以上ある場合のみ |
| 読み込めない場合 | エラー色のカード「保存済みのクレデンシャルを読み込めません」、説明、エラー内容、[初期化 (すべて削除)] (DD-07 §5.1)。空の表示は出さない |
| 一覧 (作成日時の新しい順) | カード: RP 名 (なければ RP ID)、RP ID (RP 名と異なる場合)、表示名 (ユーザー名)、作成日時、最終使用日時と署名回数 (未使用は「未使用」)、チップ「パスキー (検出可能)」/「非検出 (サーバー側保持)」、チップ「StrongBox / TEE / ソフトウェア / 不明」(ソフトウェア・不明は警告アイコンと「安全なハードウェアで保護されていません」の注記)、削除アイコン |
| 空 | 「登録済みのクレデンシャルはありません」 |

| ダイアログ | 内容 | 確定時 |
|---|---|---|
| 個別削除 | 「クレデンシャルを削除しますか?」「RP (ユーザー) の鍵を完全に削除します。」[削除] [キャンセル] | 本人確認「クレデンシャル削除のために本人確認」→ 削除 |
| 全削除 | 「すべてのクレデンシャルを削除しますか?」「N 件の鍵をすべて完全に削除します。」(件数は複数形リソース) | 本人確認「全クレデンシャル削除のために本人確認」→ 全削除 |
| 初期化 | 全削除と同じダイアログ。本文「読み込めなかったものを含め、鍵とメタデータをすべて完全に削除します。」 | 本人確認 → 全削除 (メタデータの暗号鍵も作り直す) |

## 4. SC-03 イベントログ

| 要素 | 内容 |
|---|---|
| 説明 | メモリ上のみに保持し、プロセス終了で消去される旨 |
| [消去] | 1 件以上ある場合のみ有効 |
| ログ行 | レベルアイコン (INFO 情報 / SUCCESS チェック (プライマリ色) / WARNING 警告 (ターシャリ色) / ERROR エラー (エラー色))、`HH:mm:ss  [source]`、メッセージ (等幅) |

## 5. SC-04 設定

| 区分 | 項目 | 部品 | 本人確認 |
|---|---|---|---|
| 表示 | テーマ | `ThemeSettingItem` | — |
| 本人確認 | 認証受付時間 (15〜300 秒) | `SettingItemDropdown` | — |
| | 本人確認 1 回につき認証 1 回 | `SettingItemSwitch` | OFF にする時 |
| | 生体認証のみ | `SettingItemSwitch` | OFF にする時 |
| | 確認前にかざしたら確認画面を表示 | `SettingItemSwitch` | — |
| 鍵 | StrongBox を優先 (非搭載時は無効表示) | `SettingItemSwitch` | — |
| | アテステーション (なし / 自己アテステーション) | `SettingItemDropdown` | — |
| クライアント操作 | PC からのリセットを許可 | `SettingItemSwitch` | ON にする時 |
| Bluetooth (実験的) | Bluetooth HID セキュリティキーとして使う (Bluetooth 非搭載時は無効) | `SettingItemSwitch` | — (ON 時に権限要求) |

各項目の下に説明文 (`SettingsHelpText` または説明行) を表示する。
