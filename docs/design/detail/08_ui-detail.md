## 1. 共通 (AppRoot)

| 要素 | 内容 |
|---|---|
| ドロワーのヘッダー | アプリ名、受付状態 (「認証受付中」(プライマリ色) / 「認証停止中」) |

## 2. SC-01 セキュリティキー

### 2.1 受付状態カード

| 状態 | アイコン | タイトル | 補足 | ボタン |
|---|---|---|---|---|
| 画面ロック未設定 | 鍵 | 本人確認が必要です | 画面ロックの設定が必要な旨 | [画面ロックを設定] → セキュリティ設定 |
| 待機 (IDLE) | 鍵 | 本人確認が必要です | 「認証の前に指紋 (または画面ロック) で本人確認してください…」 | [本人確認して開始] (指紋アイコン、全幅) |
| 受付中 | 解錠 (カード背景はプライマリコンテナ色) | 認証できます | 残り N 秒、プログレスバー、「本端末の背面を NFC リーダーにかざしてください」(ワンタイム時は 1 回で終了する旨) | [停止] |

- 最終使用がある場合「最終使用: 日時 (RP ID)」を表示。
- 残り秒数は 250 ms 毎に更新、切り上げ表示。live region (読み上げ) はタイトル (「認証できます / 本人確認が必要です」) のみとし、
  毎秒変わる残り秒数は含めない (TalkBack の反復読み上げを避ける)。

### 2.2 接続方式

| 行 | 状態表示 | 操作 |
|---|---|---|
| NFC | 利用可能 (カードエミュレーション) / NFC がオフです / 非対応 | NFC オフ時 [オンにする] → NFC 設定 |
| Bluetooth HID (実験的) | 設定で無効 / 権限の許可が必要 / Bluetooth がオフ / 停止中 / 開始しています / PC からの接続待ち / 接続中: ホスト名 / エラー / 利用できません | [設定] (無効時) / [開始] / [停止]。接続待ち時は [この端末を検出可能にする] |
| USB | 非対応 (理由) | なし |

### 2.3 鍵の保管

「Android キーストア (StrongBox 利用可)」または「(TEE)」、「N 件のクレデンシャル」、[管理] → SC-02。

### 2.4 最近のイベント

最新 5 件 (ログ行形式は §4)。なしの場合「イベントはありません」。[すべて表示] → SC-03。

## 3. SC-02 クレデンシャル

| 要素 | 内容 |
|---|---|
| 説明 | 鍵は端末外へ出ないこと、削除は取り消せないこと |
| [すべて削除] | エラー色のアウトラインボタン。1 件以上ある場合のみ |
| 読み込めない場合 | エラー色のカード「保存済みのクレデンシャルを読み込めません」、説明、エラー内容、[初期化 (すべて削除)] (DD-07 §5.1)。空の表示は出さない |
| 一覧 (作成日時の新しい順) | カード: タイトル (1 行目。利用者が付けたタイトル、なければ RP 名、なければ RP ID。2 行まで)、RP 名 (なければ RP ID)、RP ID (RP 名と異なる場合)、表示名 (ユーザー名)、作成日時、最終使用日時と署名回数 (未使用は「未使用」)、チップ「パスキー (検出可能)」/「非検出 (サーバー側保持)」、チップ「hmac-secret (PRF)」(hmac-secret 付きの場合)、チップ「credProtect 2: UV または ID 指定」/「credProtect 3: UV 必須」(レベル 2・3 の場合。チップは幅に応じて折り返す)、チップ「StrongBox / TEE / ソフトウェア / 不明」(ソフトウェア・不明は警告アイコンと「安全なハードウェアで保護されていません」の注記)。右端に編集アイコン (読み込めない場合は無効) と削除アイコン |
| 空 | 「登録済みのクレデンシャルはありません」 |

| ダイアログ | 内容 | 確定時 |
|---|---|---|
| タイトルの編集 | 「タイトルの編集」、入力欄「タイトル」(1 行。現在のタイトル、未設定なら空欄で既定のタイトルを薄く表示。64 コードポイントまで。入力があれば消去アイコン)、説明「このアプリ内の表示にのみ使います (サイト名やアカウント名など)。空欄にすると「既定のタイトル」を表示します。」[保存] [キャンセル] | 保存 (本人確認なし。空欄は既定に戻す)。イベントログに「renamed credential for RP ID」(logcat には RP ID を出さない) |
| 個別削除 | 「クレデンシャルを削除しますか?」「タイトル (ユーザー) の鍵を完全に削除します。」[削除] [キャンセル] | 本人確認「クレデンシャル削除のために本人確認」→ 削除 |
| 全削除 | 「すべてのクレデンシャルを削除しますか?」「N 件の鍵をすべて完全に削除します。」(件数は複数形リソース) | 本人確認「全クレデンシャル削除のために本人確認」→ 全削除 |
| 初期化 | 全削除と同じダイアログ。本文「読み込めなかったものを含め、鍵とメタデータをすべて完全に削除します。」 | 本人確認 → 全削除 (メタデータの暗号鍵も作り直す) |

## 4. SC-03 イベントログ

### 5.1 言語

TCSameuraDamMonitor と同じ方式とする。

| 項目 | 内容 |
|---|---|
| 操作 | タップで OS のアプリ別言語設定 (`Settings.ACTION_APP_LOCALE_SETTINGS`、package = 本アプリ) を開く。開けない場合はスナックバー「画面を開けませんでした。」 |
| 選択肢 | `res/xml/locales_config.xml` (Manifest の `android:localeConfig`) の `en` / `ja` と「システムのデフォルト」 |
| 説明行 | `LocaleManager.applicationLocales` が空ならシステムのデフォルト、空でなければ選択中の言語 |
| 保存 | OS がアプリ別に保存する (アプリの設定ファイルには保存しない) |
| 変更時 | OS が Activity を再生成する。このとき前面表示が一旦途切れるため、認証の受付は解除される (DD-05 §2.2) |

## 8. 注意書き (FR-20)

本アプリがテスト専用であり (PRE-01)、物理セキュリティキーの代替として使用しないこと (PRE-02) を明示する。
初回起動時のダイアログ (`ui/common/TestUseNotice.kt` の `TestUseNoticeDialog`) と、利用規約 第 2 条・第 3 条 (§9) で明示する。

| 表示箇所 | 形式 | 内容 |
|---|---|---|
| DL-03 初回起動時 | ダイアログ (戻る・外側タップでは閉じない) | タイトル「テスト専用です」、全文、「詳しくは『このアプリについて』の利用規約を参照してください。」、[理解しました] → 設定 `notice_acknowledged = true` |
| SC-06 利用規約 | 文書 | 第 2 条 (本アプリの内容と位置付け)、第 3 条 (利用の条件) |

> 1.2 の初版では SC-01・SC-04・SC-05 にも注意書きのカードを表示していたが、表示が多すぎるため削除し、
> 内容は利用規約・セキュリティポリシーに反映した。

> セキュリティキーエミュレータは、FIDO / FIDO2 (WebAuthn) を使用する Web アプリケーションのテスト用ツールです。YubiKey などの物理セキュリティキーの代替として使用しないでください。
>
> - テスト用のアカウント・環境にのみ登録してください。本番サービスや重要なアカウントには登録しないでください。

## 9. 利用規約・セキュリティポリシー (SC-06)

TCSameuraDamMonitor と同様に、「このアプリについて」から全画面の文書として表示する。

| 文書内のリンク | 4 文書間の相対リンクはアプリ内で SC-06 を開く。その他の相対リンク (`../LICENSE` 等) は GitHub (`blob/HEAD/...`)、URL・`mailto:` は外部アプリで開く (`LegalDocument.resolve`) |
